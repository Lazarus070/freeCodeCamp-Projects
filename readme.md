# Responsive Web Design Portfolio

## Overview
This repository contains five layout-driven web projects built to fulfill the requirements for the **freeCodeCamp Legacy Responsive Web Design Certification** (an intensive ~300-hour curriculum). 

The architecture focuses on semantic HTML5 and modern CSS layout modules to ensure fully responsive, mobile-first interfaces across all device viewports.

## Projects Included
1. **Call of Duty Product Landing Page:** A stylized promotional landing page featuring embedded media, sticky navigation, and flex-based product tiers.
2. **Survey Form:** A data-collection interface utilizing HTML5 validation and structured form groups.
3. **Technical Documentation Page:** A multi-section reference guide with a fixed sidebar navigation for desktop and stacked layout for mobile.
4. **Tribute Page:** A foundational responsive layout integrating scalable imagery and clean typography.
5. **Personal Portfolio Hub:** A unified, dark-mode aesthetic hub linking all certification projects *(Architecture conceptualized and deployed with AI assistance)*.

## Technical Stack
* **Languages:** HTML5, CSS3
* **Layout Modules:** CSS Flexbox, CSS Grid
* **Design Principles:** Mobile-First Design, Responsive Web Design (RWD), Accessibility (a11y)
* **Environment & Version Control:** VS Code, Git, GitHub
